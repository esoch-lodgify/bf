Black Friday banner — local test harness

Behaviour only. The banner is intentionally unstyled here.

This page supplies the four #bf-banner rules the script needs, and nothing else. On the live site Webflow provides the .bfbanner_* styling — check there that #bf-banner itself is positioned, since that id is not a Webflow class.

Locale

  • no parameters — English
  • ?lang=es · ?lang=de · ?lang=fr · ?lang=it · ?lang=pt
  • ?lang=ja — unknown, falls back to English

Display

  • ?reset=1 — clear the dismissal and show it again
  • ?bfshow=1 — show it even if dismissed or past the end date

Close it, then reload: it stays gone for 24 hours. Scroll — it should stay pinned to the bottom and overlay the content rather than push it.
